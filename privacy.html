Privacy Policy

Draft · Last updated November 1, 2026

TimeOS is a personal research project maintained by roman-khalimov, for the maintainer's own use. These pages explain the present state and the intended scope.

Oura is not connected. Its authorization callback, storage rules, and deletion workflow have not been implemented or verified. This draft does not describe an operational Oura integration.

1. Visiting this website

The page code contains no analytics, advertising, tracking scripts, forms, or cookie-setting code. It does not request access to service accounts or receive activity records, sleep data, or OAuth credentials.

These pages are intended for GitHub Pages hosting. GitHub states that it logs visitors' IP addresses for security purposes. Hosting and following external links involve processing by those providers under their own policies. See the GitHub Pages data collection notice and GitHub Privacy Statement. This site does not promise an absence of hosting logs.

2. Personal project data

Current local research uses the maintainer's own Toggl Track time entries, including timestamps, durations, descriptions, project information, and available tags. Research files and derived results are stored locally, separately from these public pages.

The planned Oura connection would read the maintainer's own sleep intervals, primarily their dates and start and end times, to provide context for a weekly review. No Oura data has been collected by TimeOS. Permissions and the exact fields to be retained remain to be finalized before collection.

There are no other TimeOS users, public accounts, or public uploads. The intended integration reads source records without editing them.

3. Use and disclosure

The purpose is the maintainer's personal weekly review. Selling personal data, advertising uses, and publishing personal records are outside the project's scope. The information website contains no personal research dataset.

No automatic transfer of personal project data to external LLM services is part of the project. The planned Oura integration excludes AI/LLM processing of Oura API data.

Toggl Track and Oura handle their own accounts and services under their respective policies. GitHub hosts the information website; it is not intended to host TimeOS credentials or personal research records.

4. Storage, security, and deletion

Existing Toggl research files are local. A fixed retention period, automatic deletion process, encryption mechanism, and backup-deletion procedure have not been verified. This policy makes no guarantee about those mechanisms or absolute security.

For the current local research, the maintainer controls the files and can inspect or manually remove them and any copies they have made. Removing a local file does not remove the original record held by a source service.

Local storage is a proposal for Oura, not a confirmed capability of the integration. Permitted storage, retention, consent withdrawal, and deletion handling must be resolved before Oura collection begins. No deletion deadline is represented here as an implemented feature.

5. Access and consent

The owner controls access to their source accounts. For a future Oura connection, authorization would be voluntary and could be withdrawn through Oura's access controls or token revocation. TimeOS does not yet provide a connect, disconnect, access-request, or deletion interface. Revoking access does not itself establish that previously saved files have been deleted.

6. Contact and changes

For general questions about this policy, use GitHub Issues. Issues and their contents are public and are processed by GitHub. Do not include health data, activity records, credentials, or other personal information. A confidential request channel has not been established.

This policy should be updated to reflect verified changes before new data-handling behavior is introduced. The date above identifies this draft; it is not a statement that the planned integration is ready.
